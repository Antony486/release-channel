what it does

Track routines without an account

Offline-first. // Every habit, streak, and note lives on the device. No sign-in screen.
Local backup / restore. // Export a single encrypted file, store it wherever you like.
Widgets, no network. // Home-screen streak widget updates without a background service.
Data collection: none. // No analytics SDK is bundled. Crash reports are opt-in, sent manually.
