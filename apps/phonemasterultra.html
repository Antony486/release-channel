what it does

Everyday maintenance, plus real privacy tools

Junk and cache cleaner. // Clears app cache, leftover install files, and residual data to free up storage.
Performance boost. // Closes background processes eating RAM and battery.
Vault. // Move photos, videos, or files into a PIN-protected hidden space — they don't show up in the gallery or file manager.
App Lock. // Require a PIN, pattern, or fingerprint before any chosen app opens, even after the phone is unlocked.
Call blocking. // Block and unblock numbers directly from your contacts and call log.
Anti-theft. // Optional: photograph anyone who fails App Lock or Vault entry, and locate the phone if it's lost — off by default.
Uninstall protection. // Device admin access is used only to require the passcode before the app itself can be removed.
permissions and why
Device admin // prevents uninstall without the passcode.
Contacts, call log, phone // block and unblock numbers.
Camera // takes a photo after repeated incorrect App Lock or Vault attempts. Off unless this feature is enabled.
Location // used only if anti-theft tracking is turned on — this is the one thing the app ever sends off the device.
Notifications // shows the app's own alerts, such as low storage warnings.
Usage stats, running apps // powers the cleaner and booster tools.
Storage, media // cache cleaning and Vault file management.
Biometric // fingerprint unlock for Vault and App Lock.
data collection

Nothing leaves the device by default. If you turn on anti-theft location tracking, the phone's location is transmitted off-device so you can locate it if it's lost or stolen — that's the only thing PhoneMasterUltra ever sends externally.
