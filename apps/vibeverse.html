what it does

A player that actually plays what you already have

Local library, real playback. // Scans your device's own audio and video — no locked-in streaming catalog required.
Podcasts and internet radio. // Subscribe to any RSS/Atom feed directly, search thousands of free radio stations — no account, no key.
Synced lyrics. // Line-by-line lyrics that highlight in time with playback, cached on-device after the first lookup.
Cast, Auto, and Wear OS. // Send playback to a Chromecast, browse your library from an Android Auto head unit, or control it from a companion watch app.
Data collection: none. // No VibeVerse analytics server exists. The only network calls are direct, on-demand requests to the lyrics/radio/podcast/cast services each feature needs.
