what it does

Diagnose the network you're actually on

Ping and traceroute. // Run either against any host, no root required.
DNS lookup. // Query A, AAAA, MX, and TXT records against a chosen resolver.
Local network scan. // List devices on your subnet with open-port detection.
Data collection: connection metadata only, on-device. // Nothing leaves the device; results aren't uploaded anywhere.
