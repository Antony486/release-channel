install guide

Installing outside the store

Android calls this "sideloading." It's a one-time setting, not a workaround.

01 / allow the source

Enable installs from this browser

Settings → Apps → Special access → Install unknown apps. Turn it on for the browser you'll download with. Android will ask again on first install as a safety check.

02 / verify

Check the checksum

Run sha256sum on the downloaded file and compare it to the hash on the app's page. If they don't match, the file changed in transit — don't install it.

03 / install

Open the APK

Tap the downloaded file, review the permissions Android shows you, and confirm. Updates install over the existing app — your data stays put.

about this channel

Why direct distribution

This site exists because store review timelines and delisting policies don't always match how fast a small, independent app actually moves. Every build here is signed with the same key across versions, so Android verifies each update comes from the same source as the last — the same guarantee a store provides, without the middleman.

Built and maintained by an independent Android developer. Source layout, checksum tooling, and a template for adding new releases are documented in the project README for anyone forking this site.
